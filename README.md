# ApexPlanet Task 3 - Advanced Search, Pagination & UI Enhancement

A PHP and MySQL based CRUD application enhanced with advanced search,
pagination, authentication, and a responsive user interface.

## 🚀 Features

- User Registration
- User Login and Logout
- Password Hashing
- Session Management
- Create Posts
- View Posts
- Update Posts
- Delete Posts
- Search Posts by Title or Content
- Pagination
- Responsive and Improved UI
- MySQL Database Integration

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- XAMPP
- Git & GitHub
